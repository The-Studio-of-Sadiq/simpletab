# M7 check: file explorer, tournament file guard and developer mode

- **Date of the scripted run:** 2026-11-25
- **Build:** simpletab `d7511ff` (Theia 1.77.0, Electron 44.9.1), `npm run build -w packages/app` after `npm run rebuild -w packages/app`
- **Laptop:** Windows 11, 11th Gen Intel Core i7-1165G7, 16 GB

The milestone's checkpoint is this manual check. Claude ran each step below in the built app, driving the window through the Chrome DevTools protocol (`--remote-debugging-port`), and recorded what happened. Steps that need a second laptop or a person's judgement are left for the author.

## Setup

1. Start the app: `npm run start -w packages/app`.
2. Run **SimpleTab: Create a demo tournament** from the command palette (F1) and press Enter at the folder prompt (blank keeps the default). The window opens the tournament folder (`~/.simpletab/demo`). (Before M8 step d the command was named "Create demo tournament" and asked nothing.)
3. For the Git steps, make the folder a repository with a committed `teams.csv`, then change `teams.csv`. (The scripted run did this from a terminal.)
