## Manual Checklist (for the author)

Prerequisite: `git` must be installed and on `PATH`, and `npm run build -w packages/app` + `npm run rebuild -w packages/app` must have completed.

1. **Launch the desktop app**
   ```powershell
   npm run start -w packages/app
   ```
   - [ ] Left activity bar shows **SimpleTab** and **Source Control** only.
   - [ ] No **Plugins / Extensions**, **Explorer / Navigator**, **Search**, **Debug**, **Testing**, or **Terminal** views appear in the activity bar, bottom panel, or top menu bar.

2. **Create or open a demo tournament**
   - [ ] Click **Create Demo Tournament** (or create/open a tournament in a chosen folder on **Setup**).
   - [ ] Confirm the window opens the tournament folder as the Theia workspace (window title reflects the tournament folder name).
   - [ ] If Theia shows a **Workspace Trust** prompt for the tournament folder, select **Trust** so `vscode.git` activates for that folder.
   - [ ] Confirm a `.gitignore` file exists in the tournament folder containing:
     ```gitignore
     *.simpletab.db
     *.simpletab.db-*
     *.simpletab
     ```

3. **Initialize git and verify database files stay ignored**
   - [ ] Open the **Source Control** panel in the left activity bar.
   - [ ] Click **Initialize Repository** (if the folder is not already a git repository).
   - [ ] Confirm `bp-demo.simpletab.db` (and any `-wal`/`-shm` or `.simpletab` files) do **not** appear under Changes (only `.gitignore` and your plain-text files should be tracked).

4. **Add a CSV, stage, and commit**
   - [ ] Create a sample CSV file inside the tournament folder, e.g. `teams.csv`:
     ```csv
     name,institution,speaker1,speaker2
     Oxford A,Oxford,Alice,Bob
     Cambridge A,Cambridge,Cara,Dan
     ```
   - [ ] Confirm **Source Control** lists `teams.csv` as an untracked file (`U`).
   - [ ] Stage `teams.csv` (and `.gitignore`) using the `+` (**Stage Changes**) button.
   - [ ] Enter a commit message (e.g. `Add initial teams CSV`) and commit.
   - [ ] Confirm **Changes** is now clean.

5. **Edit the CSV and view the diff**
   - [ ] Edit `teams.csv` (for example, rename a speaker or add a third team row) and save.
   - [ ] Confirm **Source Control** lists `teams.csv` as modified (`M`).
   - [ ] Click `teams.csv` in **Source Control** and confirm the side-by-side diff view opens showing the exact added/changed lines.
